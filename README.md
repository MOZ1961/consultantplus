# consultantplus

Транспортный bootstrap-репозиторий клиентской системы «Сеть КонсультантПлюс» для подключения к общей SE-среде.

Этот README не является информационным продуктом процесса, semantic authority, конфигурационной baseline или описанием клиентской системы. Долговременное инженерное состояние хранится только в process-owned `ArtifactInstance + exact ArtifactVersion` под `artifacts/`.

Связь с общей SE-средой устанавливается только через exact process-owned интерфейс и client-owned `TM-CM` BindingInstance. Принятие, deployment и merge являются отдельными решениями владельца.
